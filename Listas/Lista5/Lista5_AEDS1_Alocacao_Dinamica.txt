Lista 5 - Alocação Dinâmica

- Informações sobre cópias: As atividades são individuais. Caso sejam identificadas cópias, tanto

- Os enunciados desta lista foram elaborados com o auxílio do ChatGPT e posteriormente revisados,

- Para cada um dos exercícios a seguir, crie um arquivo .c contendo a função main para realização

- O código deve ser comentado, indicando as principais decisões tomadas durante a implementação.
- Nesta lista, não deve ser utilizada alocação dinâmica de memória. Portanto, não utilize as

1. Observe os dois programas a seguir, Código 1 e Código 2. Qual a diferença entre eles?
   Qual o valor impresso para ptr em cada um dos códigos? Justifique.

   Código 1                                          Código 2
   -------------------------------------------------  -------------------------------------------------
   int main()                                         int main()
   {                                                   {
       int *ptr, i;                                       int *ptr, i;
       ptr = (int *) malloc(sizeof(int));                 ptr = (int *) malloc(sizeof(int));
       *ptr = 10;                                          *ptr = 10;

       for(i = 0; i < 5; i++){                            for(i = 0; i < 5; i++){
           *ptr = *ptr + 1;                                   ptr = ptr + 1;
       }                                                   }

       printf("\nptr: %d", *ptr);                         printf("\nptr: %p", ptr);
       free(ptr);                                          free(ptr);

       return 0;                                          return 0;
   }                                                   }

2. Crie um programa em C que:
   (a) Aloque dinamicamente 5 números inteiros;
   (b) Peça para o usuário digitar os 5 números e armazene no espaço alocado;
   (c) Mostre na tela os 5 números;
   (d) Libere a memória alocada.

3. Faça um programa em C que solicite ao usuário a quantidade de alunos de uma turma e leia
   a nota de cada aluno, armazenando-a em memória alocada dinamicamente. A nota é um número
   real de dupla precisão (double). Imprima todas as notas e também a média das notas.

4. Faça um programa em C para armazenar em memória um total de 30 valores do tipo inteiro,
   usando a função de alocação dinâmica de memória CALLOC:
   (a) Atribua para os primeiros 10 inteiros os valores de 1 a 10;
   (b) Atribua para os últimos 10 inteiros os valores de 10 a 1;
   (c) Exiba na tela os 30 números.

5. Crie um programa em C que:
   (a) Aloque dinamicamente 5 números inteiros;
   (b) Peça para o usuário digitar os 5 números e armazene no espaço alocado;
   (c) Imprima os endereços onde foram armazenados os 5 números;
   (d) Realoque um espaço para digitais mais 5 números inteiros;
   (e) Peça para o usuário digitar novos 5 números e armazene no novo espaço alocado;
   (f) Imprima os endereços onde foram armazenados os 10 números;
   (g) Mostre na tela os 10 números;
   (h) Libere a memória alocada.

6. A alocação dinâmica de memória permite trabalhar com matrizes de formas diferentes, a saber:
   - Utilizando um ponteiro simples;
   - Utilizando um arranjo de ponteiro;
   - Utilizando um ponteiro para ponteiro.
   Dê exemplo de como criar, preencher e imprimir uma matriz para cada uma das formas
   mencionadas acima.

7. Faça um programa que declare uma matriz bidimensional declarada no principal (main).
   O usuário deverá declarar ponteiros para linhas e para colunas dentro do principal. Os
   ponteiros deverão ser enviados para um procedimento onde a matriz será inicializada.
   Após retornar ao principal, outra função deverá receber a matriz já preenchida pelo
   usuário e deverá imprimi-la.

8. Faça um programa em C que aloque dinamicamente uma matriz tridimensional. O programa
   deve solicitar que o usuário informe o tamanho da profundidade da matriz, a quantidade
   de linhas e a quantidade de colunas. A matriz deverá ser alocada e posteriormente
   preenchida pelo usuário usando aritmética de ponteiros. Ao final, o programa deve
   imprimir a matriz.
